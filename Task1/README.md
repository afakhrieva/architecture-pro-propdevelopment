### Категория ISO - Публичные данные

| Типы данных                                                                | Источник                                                               |
|----------------------------------------------------------------------------|------------------------------------------------------------------------|
| Информация об объектах недвижимости (описания ЖК, планировки, цены и т.п.) | `client-mart-estate-app` (БД `client-mart-estate-db`)                  |
| 3D-модели квартир, панорамы, виртуальные туры                              | `client-tour-app` (БД `client-tour-db`)                                |
| Условия бронирования, акции                                                | Витрина продаж                                                         |
| Контакты компании                                                          | Витрина продаж                                                         |

#### Оценка рисков

| Риск      | Актуальность                                                                                                                           | Оценка          |
|-----------|----------------------------------------------------------------------------------------------------------------------------------------|-----------------|
| Искажение | Злоумышленник может изменить цены, планировки или условия бронирования на витрине продаж или в 3D-турах, что подорвёт доверие клиентов | Значительный    |
| Потеря    | Удаление 3D-моделей или описаний ЖК из-за сбоя или атаки – восстанавливается из бэкапов, но временно информация будет недоступна       | Незначительный  |

Утечка, некачественные, обесценивание – не актуальны, так как данные публичные.

### Категория ISO - Внутренние данные

| Типы данных                                                                                           | Источник                                                               |
|-------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------|
| Конфигурация сервисов и архитектуры - cхемы БД, переменные окружения (не секреты), адреса серверов    | Все контейнеры (YAML, Dockerfile, Terraform)                           |
| Логи операций (без ПД) - HTTP status, latency, ID запроса (без тела)                                  | Все микросервисы                                                       |
| Метаданные CDC-потоков - список таблиц, которые реплицируются, расписание                             | CDC-коннекторы                                                         |
| Конфигурация Kafka топиков - названия топиков, количество партиций, retention                         | Kafka broker (между `client-crm-app` и `client-mart-app`)              |
| Роли и группы Active Directory (без паролей)                                                          | `Active Directory` (финансы) и `Active Directory` (прикладные системы) |
| Метрики использования приложений - RPS, ошибки, потребление CPU, RAM и пр.                            | Системы мониторинга (Prometheus, Grafana)                              |

#### Оценка рисков

| Риск            | Актуальность                                                                                                                                        | Оценка         |
|-----------------|-----------------------------------------------------------------------------------------------------------------------------------------------------|----------------|
| Утечка          | Конфигурации, схемы БД, логи без ПД, роли AD помогают злоумышленнику построить целенаправленную атаку (например, узнать адреса серверов, версии ПО) | Значительный   |
| Потеря          | Удаление логов операций или метаданных CDC – теряется возможность расследования инцидентов и восстановления работы                                  | Значительный   |
| Искажение       | Изменение конфигурации Kafka или CDC-потоков может перенаправить ПД во внешний канал                                                                | Значительный   |
| Некачественные  | Ошибки в конфигурации API (избыточные права) – уже выявлены в кейсе как проблема с партнёрскими API                                                 | Значительный   |

Обесценивание не актуально – внутренние данные не используют для принятия бизнес-решений напрямую. 

### Категория ISO - Конфиденциальные данные

ПД - персональные данные

| Типы данных                                                                                           | Источник                                                               | Правовое основание (РФ)                      |
|-------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------|----------------------------------------------|
| ПД клиентов - базовая информация (ФИО, телефон, e-mail)                                               | `client-crm-app` (БД `crm-db`), `auth-db-1` (Keycloak)                 | 152-ФЗ, категория обычных ПД                 |
| ПД клиентов - расширенная форма для сделки (Паспортные данные, СНИЛС, ИНН, доходы, адрес регистрации) | `client-crm-app`, `client-mart-app` (БД `client-mart-db`)              | Категория специальных ПД (паспорт, СНИЛС)    |
| ПД собственников - ФИО, телефон, e-mail, адрес, лицевой счёт                                          | `CRM` (`crm-tenant-db`)                                                | Обычные ПД + адрес (косвенно идентифицирует) | 
| Данные онлайн-сделок - номер договора, цена, статус регистрации в Росреестре                          | `client-mart-app` (`client-mart-db`)                                   | Коммерческая тайна + ПД                      |
| Данные оплаты ЖКУ - история платежей, задолженность, показания счётчиков                              | `tenant-core-app` (`tenant-core-db`) + интеграция с платёжной системой | Финансовая информация собственников          |
| Данные умного дома (Логи доступа) - время открытия двери, кто открыл, настройки автоматики            | `tenant-core-app`, интеграция с устройствами                           | Конфиденциальны                              |
| Данные интеграции с госорганами (СМЭВ) - номер заявки, копия договора, паспортные данные участников   | `client-mart-app` <-> СМЭВ                                             | Содержат ПД и юридически значимую информацию |
| Логи доступа к API с ПД - тело запроса, содержащее ФИО или телефон                                    | Nginx, API Gateway (на схеме явно не указаны)                          | Риск утечки, если логи не маскируются        |
| Контракты с партнёрами - договоры с УК, тарифы, условия интеграции                                    | Внутренние документы, возможно в `accountant-service-1`                | Коммерческая тайна                           |
| Финансовая отчётность - бухгалтерские проводки, себестоимость строительства                           | `accountant-service-1`                                                 | Коммерческая тайна                           |

#### Оценка рисков

| Риск           | Актуальность                                                                                                                                                                                                                                                                                                                                           | Оценка                    |
|----------------|--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|---------------------------|
| Утечка         | - Без маскирования аналитики BI видят паспорта и СНИЛС  <br> - API партнёров с избыточными правами -> Партнёр из одной УК видит данные другой УК  <br> - Две CRM -> дублирование ПД, вероятность ошибок доступа. Жалобы клиентов на чужие ФИО в ЛК – уже случилась микро-утечка. <br> - Логи API без маскирования -> возможность получить ПД из логов  | Критический               |
| Потеря         | - Резервное копирование есть, но глубина не указана, восстановление может быть неполным. <br> - Удаление данных о сделках или платежах (например, из `client-mart-db` или `tenant-core-db`).                                                                                                                                                           | Значительный/Критический  |
| Искажение      | Несанкционированное изменение данных сделки (цена, объект) через скомпрометированный API или прямую БД ведёт к финансовым потерям и юридическим спорам.                                                                                                                                                                                                | Критический               |
| Некачественные | Двойная регистрация клиентов в `client-crm-app` и `CRM` (дубли), рассогласование справочников – причина ошибок в ЛК и недовольства.                                                                                                                                                                                                                    | Критический               |
| Обесценивание  | Невозможность использовать ML/AI из-за "грязных" данных (дубли, противоречия).  Блокировка стратегических инициатив, потеря конкурентных преимуществ.                                                                                                                                                                                                  | Критический               |


### Категория ISO - Секретные данные

| Типы данных                                                                                             | Источник                                               | Обоснование (риски при компрометации)                         |
|---------------------------------------------------------------------------------------------------------|--------------------------------------------------------|---------------------------------------------------------------|
| Учётные данные (хэши паролей, токены сессий) клиентов и собственников                                   | `auth-db-1` (Keycloak)                                 | Полный захват аккаунта, онлайн-сделки, управление умным домом |
| Учётные данные бухгалтеров - логин и хэш пароля бухгалтера, токен доступа к фин. системе                | `Active Directory` (финансы) + `accountant-service-1`  | Подделка платежей, кража отчётности                           |
| Учётные данные аналитиков BI - логин и пароль аналитика, доступ к Greenplum                             | `Active Directory` (прикладные системы, которая у DWH) | Массовая выгрузка всех ПДн из DWH                             |
| Учётные данные администраторов (менеджеров) с расширенными правами - логин и пароль администратора CRM  | `client-crm-app`, `CRM` – если есть роли "super admin" | Изменение любых данных клиентов, сделок                       |
| Мастер-пароли и ключи умного дома                                                                       | Системы управления домофоном, автоматикой              | Физический доступ в жилые помещения                           |
| Сертификаты и приватные ключи для СМЭВ - ключ электронной подписи сделок                                | `client-mart-app` (интеграция с госорганами)           | Подделка сделок                                               |
| Ключи шифрования БД - мастер-ключ TDE, ключи для шифрования колонок с паспортами и т.п.                 | Все базы данных                                        | Расшифровка всех ПД в случае утечки копий БД                  |
| Токены доступа партнёров (УК, поставщики ресурсов)                                                      | `tenant-core-app` (интеграция с внешними API)          | Партнёр может получить чужие данные                           |
| Учётные записи администраторов ЦОД / облака - логин и пароль от приватного облака, доступ к гипервизору | Не показаны, но подразумеваются                        | Полный контроль над всей инфраструктурой                      |
| Резервные копии секретов - копии ключей шифрования, сертификатов                                        | Система backup (настроена, но глубина не уточнена)     | Дополнительный канал утечки                                   |

#### Оценка рисков

| Риск           | Актуальность                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    | Оценка          |
|----------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-----------------|
| Утечка         | - Учётные данные клиентов -> захват аккаунтов, фиктивные онлайн-сделки, открытие умного дома.  <br> - Сертификатов СМЭВ -> подпись поддельных сделок, юридические риски. <br> - Мастер-ключа TDE -> расшифровка всех БД. <br> - Токены партнёров -> доступ к чужим данным (уже проблема в кейсе).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               | Критический     |
| Потеря         | - Учётные данные клиентов -> массовый сброс паролей, коллапс техподдержки, потеря доступа в ЛК, оплате ЖКУ и умному дом. <br> - Учётные данные сотрудников -> невозможность управлять доступом, блокировка входа в системы (DWH, CRM, фин. учёт), паралич IT-операций. <br> - Ключи умного дома -> cобственники не могут открыть квартиру через приложение. <br> - Сертификаты СМЭВ -> невозможно подписывать договоры с Росреестром. Остановка онлайн-сделок, срыв обязательств перед клиентами. <br> - Мастер-ключи TDE (БД) -> все зашифрованные БД становятся навсегда недоступны. Бэкапы бесполезны без ключа. Остановка всех сервисов. <br> - Мастер-пароли инфраструктуры -> Остановка всей ИТ-инфраструктуры: невозможно зайти на серверы, развернуть резервные копии, управлять сетью. | Критический     |
| Искажение      | - Изменение учётных данных администратора в AD -> блокировка доступа сотрудников. <br> - Подмена сертификата СМЭВ -> недействительность сделок. <br> и т.п.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Критический     |
| Некачественные | Маловероятно для секретных данных, так как они обычно генерируются системой. Но если сертификат истёк и не обновлён - это технический сбой.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     | Незначительный  |

Обесценивание не актуально
